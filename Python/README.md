# Python

[problem_set_1.py](problem_set_1.py) contains 20 small exercises from the Python course:

1. Basic arithmetic with user input
2. Factorial with error handling
3. Fibonacci sequence
4. Prime number check for multiple inputs
5. List comprehension with filtering
6. Reverse a string and check for palindromes
7. Sum of digits
8. Maximum of a list
9. Simple calculator
10. Count vowels
11. Random number in a range
12. Greatest common divisor
13. Sort a list
14. Dictionary operations
15. Celsius and Fahrenheit conversion
16. Word count and longest word
17. Merge two lists without duplicates
18. Check if a list is sorted
19. Matrix addition
20. Common elements of two lists

Run it with `python problem_set_1.py`. The exercises run one after another and ask for input.
