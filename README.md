# UNI

Projects and exercises from my Informatics studies, plus extra practice added later.

The repo has two clearly separated parts:

| Part | What it is |
|------|------------|
| **Coursework** (top level folders) | The original work I did at university. Only cleaned up: files renamed, junk removed, small bugs fixed. |
| **[practice/](practice)** | Additional university level exercises added later to keep practising. **Not part of the original coursework.** |

## Coursework

| Folder | Stack | What's inside |
|--------|-------|---------------|
| [VisualBasic-6](VisualBasic-6) | Visual Basic 6 | Desktop apps: ATM simulator, currency converter, Paint clone, puzzle game, web browser, encryption tool, database UI, exam registration |
| [DotNet](DotNet) | C# | 19 console exercises: LINQ, loops, switch, recursion, classes |
| [PHP](PHP) | PHP | 20 exercises: functions, strings, arrays, closures |
| [SQL-DBMS](SQL-DBMS) | SQL Server | Rent a car database: ER diagram, schema, sample data and queries |
| [Bootstrap5](Bootstrap5) | HTML, CSS, Bootstrap | Responsive one page website |
| [PiS](PiS) | Word, Excel | Information systems course project with database design and financial plan |
| [Python](Python) | Python | Problem set with 20 small exercises |

## Practice
