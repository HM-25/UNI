# Practice

Additional exercises added after the original coursework, to keep practising the same subjects.
**These are not part of the university coursework** in the folders above.

Everything here is kept at university level and each exercise has a comment at the top explaining the task and the topics it covers.

| Folder | How to run |
|--------|-----------|
| [python](python) | `python 01_student_grades.py` and so on. Tests: `python -m unittest test_exercises.py` |
| [csharp](csharp) | Each file is a standalone console program: `csc 01_Shapes.cs` or paste into a new console project |
| [php](php) | `php 03_oop_shopping_cart.php`, or `php -S localhost:8000` for the form and CRUD pages (PHP 8+) |
| [sql](sql) | Run the scripts in order in SQL Server Management Studio: schema, data, queries |
| [web](web) | Open `web/todo/index.html` in a browser |

## Exercises

### Python
1. **Student grades**: read a CSV file, calculate averages, write a report
2. **Bank account**: classes, inheritance and custom exceptions
3. **Sorting and searching**: bubble, selection, insertion and merge sort, binary search
4. **Library system**: menu driven console app that saves data to JSON
5. **Unit tests** for exercises 2 to 4

### C#
1. **Shapes**: abstract class, inheritance, polymorphism, Heron's formula
2. **Student records**: LINQ with Where, OrderBy, GroupBy and anonymous types
3. **Generic stack**: own `MyStack<T>` implementation, used to check balanced brackets
4. **Inventory**: Dictionary, exceptions and saving to a CSV file

### PHP
1. **Contact form**: server side validation, XSS protection, sticky form values
2. **Students CRUD**: PDO with SQLite and prepared statements
3. **Shopping cart**: classes, interfaces and discounts

### SQL
Redesign of the coursework rent a car database with proper foreign keys and a rentals table, followed by 10 queries: joins, aggregates, subqueries, a view and two stored procedures.

### Web
A to-do list in plain JavaScript: DOM manipulation, event delegation, filters and localStorage.
