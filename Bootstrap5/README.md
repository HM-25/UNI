# Bootstrap website

A responsive one page website template from the web design course: navigation bar, image carousel, jumbotron, feature sections, team cards and a contact footer.

Open [index.html](index.html) in a browser to view it.

**Built with:** HTML, CSS, Bootstrap 4, jQuery and Font Awesome (loaded from CDNs).

## Cleanup notes

`index.html` had over 1 MB of empty bytes at the start, which made it look like a huge file. The padding was removed; the page is unchanged.
